# Master User Guide & FAQs

Welcome to the comprehensive **Hexbuffer User Guide**. This reference manual is designed to help you maximize efficiency, streamline your application testing workflows, and get the best experience from the Hexbuffer platform.

## Workspace Productivity Tips

### 1. Master Keyboard Shortcuts
Speed up your daily workflow with built-in desktop shortcuts:

| Shortcut (macOS / Win) | Action |
| :--- | :--- |
| `Cmd + R` / `Ctrl + R` | Send selected request to **Repeater** |
| `Cmd + I` / `Ctrl + I` | Send selected request to **Invoker (Fuzzer)** |
| `Cmd + K` / `Ctrl + K` | Open AI Assistant / Command Palette |
| `Cmd + F` / `Ctrl + F` | Focus real-time traffic search bar |
| `Cmd + \` / `Ctrl + \` | Toggle Left Navigation Sidebar |
| `Cmd + Shift + C` | Send selected request/response to **Monaco Comparer** |
| `Cmd + Enter` / `Ctrl + Enter` | Forward intercepted request or dispatch active Repeater request |

## Performance & Hygiene Best Practices

### Optimizing Traffic Diagnostics
- **Target Scope Hygiene**: Always define your domain target scope (e.g., `*.myapp.dev`) before starting extensive capture sessions. This filters out background operating system updates and third-party browser noise.
- **Database Compression**: Hexbuffer automatically manages capture logs in a local SQLite database with compression, allowing you to store extensive sessions without excessive disk usage.

### AI Copilot Efficiency
- **Provide Context**: When asking the AI copilot to diagnose an issue, select the relevant request in Live Traffic so the AI can automatically read request headers and response bodies.
- **Local Models for Offline Work**: If auditing confidential internal targets or working offline, configure local models via Ollama or LM Studio in **Settings -> AI Configuration**.

## Frequently Asked Questions (FAQ)

### Q1: Why is HTTPS traffic showing certificate warning errors in my browser?
**Answer**: You need to install Hexbuffer's Root CA Certificate into your operating system or browser's trusted certificate authority store. Go to **Settings -> CA Certificate Manager**, click **Install to System Trust Store** (or export the certificate), and restart your browser.

### Q2: How do I export my capture data to share with teammates?
**Answer**: Select requests in the **Live Traffic** grid, right-click, and choose **Export to HAR**, **Export to CSV**, or **Copy as cURL**.

### Q3: Can I run Hexbuffer completely offline without an internet connection?
**Answer**: Yes! Hexbuffer is a native desktop application. All core proxy diagnostics, repeater replaying, fuzzing, port scanning, and local AI capabilities (via Ollama or LM Studio) run 100% locally on your machine.

### Q4: How does Peer Discovery and Sync work?
**Answer**: Hexbuffer includes on-demand local network peer discovery, allowing team members on the same local subnet to share session captures and scope configurations without routing data through external cloud servers.
