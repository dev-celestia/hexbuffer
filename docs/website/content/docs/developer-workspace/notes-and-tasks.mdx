# Markdown Workspace, Kanban & Desktop Widgets

Keep your research findings, API specifications, testing notes, and project tasks perfectly organized alongside your network diagnostics without leaving **Hexbuffer**.

---

## Rich Markdown Document Workspace

The **Markdown Workspace** provides a clean WYSIWYG rich text editor:
- **Rich Text & Code Formatting**: Write documentation with syntax-highlighted code blocks, tables, callouts, and mathematical formulas.
- **Export to PDF & Markdown**: Export finished technical reports, audit summaries, or client deliverables to formatted PDF documents with a single click.
- **Local File Sync**: Syncs directly with your local workspace directory files.

---

## Integrated Kanban Task Board

Track your testing progress, security findings, and pending tasks using the interactive **Kanban Board**:

### Features & Workflow Integration
- **Custom Columns**: Organize work items into columns like `Backlog`, `In Progress`, `Under Review`, and `Completed`.
- **Link Traffic & Requests**: Attach specific HTTP request IDs, Repeater tabs, or error logs directly to Kanban task cards for full traceability.
- **AI Task Creation**: Ask the AI assistant to summarize identified issues into actionable Kanban task cards automatically.

---

## Modular Desktop Dashboard Widgets

The Hexbuffer **Desktop** acts as your central command hub with modular, draggable widgets:

- **Target Scope Widget**: Toggle active target domain scopes and review traffic matching statistics.
- **Proxy Control Widget**: Real-time proxy status, active port display, and one-click toggle.
- **VPN / Upstream Proxy Widget**: Configure upstream SOCKS5 / HTTP proxy chaining.
- **Clipboard History Widget**: Quickly recall recently copied tokens, URLs, and curl snippets.
- **Collections & Recents Widgets**: Access pinned request collections and recently opened sessions.
- **Scratchpad Widget**: Fast, persistent scratch area for transient payloads and notes.
- **Shortcut Manager**: Interactive reference for all keyboard shortcuts and custom hotkey assignments.
