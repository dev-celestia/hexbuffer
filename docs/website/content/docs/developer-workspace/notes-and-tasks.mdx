# Markdown Workspace & Kanban Task Management

Keep your research findings, API specifications, testing notes, and project tasks perfectly organized alongside your network diagnostics.

---

## Rich Markdown Document Workspace

The **Markdown Workspace** provides a WYSIWYG rich text editor powered by Milkdown / MDX:
- **Rich Text & Code Formatting**: Write clean documentation with syntax-highlighted code blocks, tables, callouts, and mathematical formulas.
- **Export to PDF & Markdown**: Export finished technical reports or client deliverables to professionally formatted PDF documents with a single click.
- **Live Sync**: Links directly with your local project workspace files.

---

## Integrated Kanban Task Board

Track your testing progress, security findings, and pending tasks using the interactive **Kanban Board**:

### Features & Workflow Integration
- **Custom Columns**: Organize work items into columns like `Backlog`, `In Progress`, `Under Review`, and `Completed`.
- **Link Traffic & Requests**: Attach specific HTTP request IDs, Repeater tabs, or error logs directly to Kanban task cards.
- **AI Task Creation**: Ask the AI assistant to summarize identified issues into actionable Kanban task cards automatically.
