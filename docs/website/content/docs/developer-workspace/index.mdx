# Developer Workspace Utilities & Mock Forge

To provide a complete developer environment, hexbuffer integrates essential productivity tools directly into the desktop application—eliminating the need to switch between terminal windows, mock servers, and file managers.

---

## Mock Forge API Server

Building or testing front-end applications before backend APIs are ready? **Mock Forge** lets you create and run local API mock servers with configurable route rules in seconds.

### Key Capabilities
- **Custom Route Rules**: Define custom endpoints (e.g., `GET /api/v1/users`, `POST /api/v1/checkout`).
- **Dynamic Response Templates**: Return custom HTTP status codes (`200`, `201`, `400`, `500`), headers, and JSON mock payloads.
- **Latency Simulation**: Add artificial response delays (e.g., 300ms) to test front-end loading states and spinner animations under poor network conditions.

---

## Integrated PTY Shell Terminal

Never switch to an external terminal window again! hexbuffer includes a full-featured pseudo-terminal (PTY) powered by `xterm.js`.

- **Multi-Tab Terminal Sessions**: Open multiple terminal tabs connected directly to your operating system shell (`zsh`, `bash`, or `PowerShell`).
- **Direct Workspace Path**: Opens automatically in your active project workspace directory.
- **AI Terminal Assistance**: Interact with the AI copilot to generate complex terminal shell commands, run diagnostic scripts, or inspect system processes.

---

## File Explorer & Scratchpad

- **Built-in File Explorer**: Browse, view, and edit local files, scripts, logs, and project assets directly within hexbuffer.
- **Quick Scratchpad**: A lightweight text scratchpad for pasting temporary API keys, curl snippets, notes, or transient test data.
