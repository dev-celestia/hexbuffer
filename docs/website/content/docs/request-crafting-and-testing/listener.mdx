# Out-of-Band (OOB) Listener & Collaborator

Modern cloud architectures and microservices frequently perform asynchronous background operations—such as dispatching verification emails, triggering third-party webhooks, processing message queues, or resolving remote asset URLs.

The **Out-of-Band (OOB) Listener** in Hexbuffer provides dedicated server endpoints to capture and verify these asynchronous callbacks and background network interactions that produce no immediate front-end HTTP response.

---

## Why Out-of-Band Testing Matters

Standard HTTP testing only monitors immediate synchronous client-server responses. However, many critical vulnerabilities and features only reveal themselves out-of-band:

- **Server-Side Request Forgery (Blind SSRF)**: Confirm whether a backend microservice inappropriately initiates outbound network connections or DNS queries to external domains.
- **Blind Vulnerability Confirmation**: Confirm blind SQL injection, blind XXE (XML External Entity), or blind command execution via external DNS resolutions or HTTP callbacks.
- **Webhook & Callback Verification**: Verify that external payment gateways, OAuth providers, or partner webhooks correctly invoke your callback URLs with expected payload structures.
- **Asynchronous Mail & DNS Services**: Audit whether background workers properly execute DNS MX resolutions or transmit transactional emails.

---

## Step-by-Step Usage

1. **Open the Listener Tab**: Click **Listener** in the main sidebar.
2. **Generate Unique Callback Domain**: Click **Generate OOB Hostname**. Hexbuffer generates a unique temporary subdomain (e.g., `oob-89342.collaborator.hexbuffer.dev`).
3. **Inject Hostname into Target**: Insert the generated subdomain into your application's input fields (such as webhook URLs, profile avatar fetchers, or PDF generator endpoints).
4. **Monitor Incoming Events**: Watch the real-time event table. As soon as the target server interacts with your domain, Hexbuffer logs:
   - **Protocol**: HTTP, HTTPS, DNS, or SMTP.
   - **Client IP & Timestamp**: Originating server IP and sub-millisecond arrival time.
   - **HTTP Details**: Request method, URI path, user-agent, headers, and request body.
   - **DNS Details**: Query record type (`A`, `AAAA`, `MX`, `TXT`, `CNAME`).
   - **SMTP Details**: Sender, recipient addresses, and raw email message contents.

---

## Key Benefits

- **Complete Visibility**: Uncover backend server activity that produces zero feedback in the browser.
- **Webhook Validation**: Inspect header structures, HMAC signatures, and JSON schemas for incoming webhooks.
- **Safe & Contained**: Isolate asynchronous testing in a controlled collaborator environment.
