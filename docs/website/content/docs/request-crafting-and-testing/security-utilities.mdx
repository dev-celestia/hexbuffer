# Security & Vulnerability Testing Suite

To ensure web applications are resilient against modern application security threats, **Hexbuffer** includes specialized, context-aware testing modules for **SQL Injection (SQLi)** and **Cross-Site Scripting (XSS)** payload generation and validation.

---

## SQL Injection Generator & Tester

The **SQL Injection** tool helps developers and security engineers identify database injection vulnerabilities and test whether backend database layers properly sanitize input parameters.

### Supported Injection Vectors
- **Error-Based SQLi**: Generates payloads designed to trigger syntax or type conversion errors across specific database engines, revealing schema structure in error messages.
- **Boolean-Based Blind SQLi**: Injects true/false boolean assertions (e.g., `' OR 1=1 --` vs `' OR 1=2 --`) to infer database state based on subtle differences in response content or HTTP status codes.
- **Time-Based Blind SQLi**: Injects database sleep/delay functions (e.g., `pg_sleep()`, `WAITFOR DELAY`, `SLEEP()`) to confirm injection vulnerabilities when applications return identical responses for all inputs.
- **UNION-Based SQLi**: Injects `UNION SELECT` statements to determine column counts, data types, and extract database records.

### Database Dialect Targeting & Tamper Scripts
- **Dialect Optimization**: Tailor payloads specifically for **MySQL**, **PostgreSQL**, **SQLite**, **Microsoft SQL Server (MSSQL)**, and **Oracle**.
- **Tamper Scripts**: Apply automated evasion transformations to test Web Application Firewall (WAF) rule robustness:
  - Space-to-comment conversion (`/**/`)
  - Hexadecimal and Unicode encoding
  - Random case alterations (`uNiOn sElEcT`)
  - Double URL encoding (`%2527`)

## XSS Payload Generator & Encoder

The **XSS Generator** constructs context-aware payload vectors to test whether web applications properly sanitize and escape untrusted data rendered in browser contexts.

### Context-Aware Payload Categories
- **HTML Context**: Payloads for insertion directly between HTML tags (e.g., `<div>{{payload}}</div>`).
- **Attribute Context**: Payloads designed to break out of HTML attributes (e.g., `<input value="{{payload}}">` or `<a href="{{payload}}">`).
- **JavaScript Context**: Payloads tailored for execution inside existing inline `<script>` blocks or JSON variables.
- **DOM XSS Polyglots**: Compact multi-context strings designed to execute successfully across various browser parsing states.

### Filter Bypass & Encoding Matrix
- Nested encoding options: URL encoding, Base64, HTML Entity Decimal/Hex, Unicode Escapes, and String.fromCharCode transformations.
- Modern event-handler variants (`onerror`, `onload`, `onfocus`, `ontoggle`, `onanimationstart`) that bypass legacy regex filters targeting `<script>` tags.

## Remediation & Defensive Best Practices

Testing with Hexbuffer provides actionable guidance for engineering teams:

> [!IMPORTANT]
> **Defend Against SQL Injection**: Always use prepared statements, parameterized queries, or modern Object-Relational Mappers (ORMs). Never concatenate user input directly into SQL strings.

> [!TIP]
> **Defend Against XSS**: Implement strict **Content Security Policy (CSP)** headers, enforce contextual HTML output escaping, and utilize framework-level protections (such as React's JSX auto-escaping or trusted types).
