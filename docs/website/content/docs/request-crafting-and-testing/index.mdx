# Repeater & Request Crafting

The **Repeater** module is an interactive sandbox designed for manual request manipulation and API testing. It allows you to take any captured HTTP or WebSocket request, modify its headers, query parameters, authentication tokens, or body payloads, and dispatch it to the server repeatedly to observe how responses change.

---

## Core Capabilities

### 1. Interactive Multi-Tab Workspace
- **Independent Request Tabs**: Work across multiple API endpoints concurrently without losing unsaved modifications.
- **Tab Customization**: Reorder, rename, duplicate, and color-code tabs for different microservices or user sessions.
- **Session Replay History**: Browse previous iterations of requests sent within the same tab, allowing you to roll back changes easily.

### 2. Rich Request Editor & Formatter
- **Method & URL Bar**: Rapidly switch methods (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`) and edit query parameters in a dedicated table or raw URL string.
- **Header Management**: Key-value table editor with auto-completion for standard HTTP headers, bulk edit mode, and one-click toggle to disable individual headers.
- **Body Formats**: Syntax-highlighted editors with automatic formatting and validation for:
  - JSON (with schema validation)
  - Raw text / XML / HTML / GraphQL
  - URL-encoded form data (`application/x-www-form-urlencoded`)
  - Multipart form uploads (`multipart/form-data`)

### 3. Pre-Request Scripts & Test Assertions
Automate dynamic parameters and response validation with a sandboxed JavaScript runtime:
- **Pre-Request Scripts**: Dynamically calculate HMAC authentication signatures, generate dynamic UUIDs/timestamps, or refresh expired authorization tokens before sending.
- **Post-Response Test Assertions**: Validate responses automatically with assertion checks:
  - Assert HTTP status code equals `200`
  - Assert response time is under `300ms`
  - Validate JSON schema properties and extract response values into environment variables

### 4. WebSocket Support
Repeater supports full two-way WebSocket testing:
- Establish persistent connections to `ws://` and `wss://` endpoints.
- Dispatch custom text or binary frames on-demand.
- Monitor real-time bidirectional message streams with opcode classification and millisecond timestamps.

### 5. Environment Variables & Templates
Define environment variables (such as `{{baseUrl}}`, `{{apiToken}}`, `{{userId}}`) to switch effortlessly between local development, staging, and production environments without editing request templates manually.

---

## Step-by-Step Usage

1. **Send Request to Repeater**: From the **Live Traffic** grid, right-click any request and click **Send to Repeater** (or press `Cmd+R` / `Ctrl+R`).
2. **Modify Request**: Edit query parameters, update authentication headers, or change JSON body values.
3. **Dispatch Request (`Cmd+Enter` / `Ctrl+Enter`)**: Click **Send** to transmit the request.
4. **Analyze Response**: Inspect formatted response headers, status codes, round-trip latency, and rendered JSON/HTML in the response pane.
5. **AI Analysis**: Click **Ask AI** to have the built-in copilot diagnose errors, explain response codes, or suggest edge-case test payloads.

## Best Practices

> [!TIP]
> **Use Pre-Request Scripting for Auth**: If your API requires request signing (such as AWS SigV4 or custom cryptographic tokens), write a reusable pre-request script in Repeater to calculate signatures automatically on every send!
