# Repeater & Request Crafting

The **Repeater** module is an interactive sandbox designed for manual request manipulation and API testing. It allows you to take any captured HTTP request, modify its headers, query parameters, authentication tokens, or body payloads, and dispatch it to the server repeatedly to observe how responses change.

---

## Core Capabilities

### 1. Workspace-Based Organization
- **Workspaces**: Group related requests into workspaces and switch between them for different projects or test targets.
- **Collection Tree Sidebar**: Organize requests in a hierarchical collection tree with drag-and-drop reordering, inline creation, and import dialogs.
- **Request Deletion**: Delete individual requests (with a permanent-delete confirmation) and manage workspaces safely with a guard preventing deletion of the last workspace.

### 2. Rich Request Editor & Formatter
The **Forge** panel provides a raw request editor with dedicated request and response views:
- **Method & URL Bar**: Rapidly switch methods (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`, or a custom method) and edit query parameters.
- **Header Management**: Key-value table editor with bulk edit mode and per-header toggles.
- **Body Formats**: Syntax-highlighted editors with automatic formatting for JSON, raw text, XML, HTML, GraphQL, URL-encoded form data, and multipart uploads.
- **Editor Linting**: The request editor highlights malformed request syntax before you send.

### 3. Pre/Post-Request Scripting
Automate dynamic parameters with a sandboxed JavaScript runtime:
- **Pre-Request Scripts**: Dynamically calculate signatures, generate UUIDs/timestamps, or refresh expired authorization tokens before sending.
- **Post-Request Scripts**: Process responses and extract values after each send.

### 4. Environment Contexts
Define environment contexts with per-context variables (such as `{{baseUrl}}`, `{{apiToken}}`) to switch effortlessly between local development, staging, and production environments. The environments dialog lets you manage contexts and variables in one place, with a context selector always available in the editor.

---

## Step-by-Step Usage

1. **Send Request to Repeater**: From the **Live Traffic** grid, right-click any request and click **Send to Repeater**.
2. **Modify Request**: Edit query parameters, update authentication headers, or change JSON body values.
3. **Dispatch Request**: Click **Send** to transmit the request.
4. **Analyze Response**: Inspect formatted response headers, status codes, round-trip latency, and rendered JSON/HTML in the response pane.

---

## Best Practices

> [!TIP]
> **Use Pre-Request Scripting for Auth**: If your API requires request signing (such as AWS SigV4 or custom cryptographic tokens), write a reusable pre-request script in Repeater to calculate signatures automatically on every send!
