# Embedded Browser & Automated Site Crawler

**Hexbuffer** features an **Embedded Browser & Site Crawler** module that seamlessly integrates web browsing and automated application reconnaissance into your desktop security environment. 

You no longer need an external browser to navigate target applications—browse directly within Hexbuffer while every HTTP request, cookie, script, and web resource is automatically logged to your Live Traffic grid.

---

## Embedded Web Browser

- **Integrated WebView**: Fully functional web browser viewport supporting modern HTML5, CSS3, JavaScript, and WebSockets.
- **Automatic Proxy Binding**: Pre-configured to route all internal web traffic through Hexbuffer's MITM proxy without requiring external proxy plugins or manual network configuration.
- **DevTools & Console**: Access browser developer tools, inspect DOM elements, and view JavaScript console logs side-by-side with network traffic.

---

## Automated Breadth-First (BFS) Web Crawler

Discover hidden endpoints, unlinked assets, and API routes across target web applications with the built-in automated web crawler.

### How the Crawler Works
1. **Target URL**: Enter a starting URL (e.g., `https://myapp.dev`).
2. **Crawl Depth & Limits**: Set maximum link crawl depth (e.g., 3 levels deep) and max page count limits.
3. **BFS Exploration**: The crawler recursively discovers links, form targets, external JavaScript assets, and API routes using Breadth-First Search (BFS).
4. **Interactive Tree & Panels**:
   - **Crawl Tree Panel**: Visual hierarchy of discovered sitemaps, paths, and endpoints.
   - **Action Log Panel**: Real-time log of crawler requests, crawl status, and response codes.
   - **Page Detail Panel**: In-depth view of discovered page elements, forms, and scripts.
   - **AI Insights Panel**: Hexbuffer's AI engine automatically flags broken links, 404 routes, missing security headers, and console exceptions.
