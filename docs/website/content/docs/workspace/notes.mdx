# Notes & Scratchpad

The **Notes** module is a persistent, multi-tab scratchpad for quick notes, scripts, markdown documentation, and architecture sketches—shared with the Desktop Scratchpad widget so your notes are always within reach.

---

## Multi-Tab Scratchpad

- **Independent Tabs**: Keep multiple notes open at once with inline tab renaming, close-to-left/right, and close-all actions. Closing a tab keeps the note in your library.
- **Two View Modes**: Switch between the **Editor** (visual rich-text/markdown editing) and **Code** (raw markdown source) modes per note.
- **Persistence**: Notes are stored in the local database and shared with the **Scratchpad Widget** on the Desktop dashboard. A generous note cap keeps your library manageable, with a toast warning as you approach it.

---

## Drawing Canvas

Sketch architecture diagrams and flows without leaving the app:

- **Object Tools**: Select, pan, pen, line, arrow, rectangle, diamond, ellipse, text, and eraser—with resize handles, duplicate/delete actions, and adjustable stroke widths.
- **Grids & Styling**: Toggle dot/line/no grids and adjust object appearance from the style submenu.
- **Built-in Templates**: Start from predefined templates (e.g., a 3-tier system architecture) that pre-populate the canvas.
- **Insert into Notes**: Renderings are exported as PNG images (saved into the app's File Explorer under `scratchpads/`) and inserted at the cursor as markdown image links.

---

## Saved Notes Manager

Open the manager dialog to organize your note library:

- **Search & Filter**: Search by name or content, and filter across all notes, currently open tabs, or closed notes.
- **Sorting**: Sort by updated, created, or title—ascending or descending.
- **Note Actions**: Duplicate, export as a markdown (`.md`) file download, copy to clipboard, rename, or permanently delete with confirmation.
