The site is a Next.js 16 static export (`output: 'export'`) powered by Fumadocs. Content lives in `content/docs/` as MDX files plus per-folder `meta.json` frontmatter; `source.config.ts` declares the docs collection with Zod schemas (`pageSchema`, `metaSchema`) and enables processed Markdown inclusion. At build time `fumadocs-mdx` generates a virtual `collections/server` module that the runtime source loader (`lib/source.ts`) consumes via `loader()` to produce typed page trees, image URLs, and markdown URLs. The App Router structure separates concerns: `app/layout.tsx` wraps everything in `RootProvider`; `app/(docs)/layout.tsx` applies `DocsLayout` with the page tree; `app/(docs)/[[...slug]]/page.tsx` resolves pages, renders MDX through `components/mdx.tsx` (which merges default Fumadocs MDX components with custom overrides), and provides metadata including OpenGraph images. Additional API routes expose search (`api/search/route.ts` via `createFromSource`), LLM-friendly text endpoints (`llms.txt`, `llms-full.txt`, `llms.mdx`), and OG image generation (`og/docs/[...slug]/route.tsx`). Shared utilities live in `lib/` (`cn.ts`, `shared.ts`, `layout.shared.tsx`, `source.ts`).
