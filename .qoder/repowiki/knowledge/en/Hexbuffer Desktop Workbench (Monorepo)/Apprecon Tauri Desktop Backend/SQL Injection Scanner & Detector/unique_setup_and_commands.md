The scanner is invoked through Tauri commands rather than direct Rust calls: `start_sqli_scan(app_handle, state, SqliScanConfig)` returns a `SqliScanResult` after emitting `sqli-progress-{scan_id}` events on the Tauri event bus; `stop_sqli_scan` sets an atomic cancellation flag checked via `get_sqli_scan_state`. A local `urlencoding` module is used instead of the `urlencoding` crate.
