Rust with Tauri framework; uses `tauri_plugin_opener`, `tauri_plugin_dialog`, `tauri_plugin_fs`, `tauri_plugin_process`, `tauri_plugin_clipboard_manager`, `tauri_plugin_shell`, `tauri_plugin_os`, `tauri_plugin_pty`, `tauri_plugin_notification`, and `tauri_plugin_updater` (desktop-only via `#[cfg(desktop)]`). Tokio runtime configured with 32 worker threads. reqwest for CDP HTTP calls, chrono for timestamps, serde/serde_json for serialization.
