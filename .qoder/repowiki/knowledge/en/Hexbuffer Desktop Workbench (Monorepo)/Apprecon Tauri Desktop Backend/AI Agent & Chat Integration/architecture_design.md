The module is organized as a Tauri command layer (`mod.rs` + `commands.rs`) delegating to feature-specific submodules: `chat.rs` handles streaming chat via `hexbuffer_ai::AiEngine`, `auto_mark.rs` provides invoker-marker suggestion, `keyring.rs` wraps the `keyring` crate for OS credential storage with an in-process `OnceLock<Mutex<BTreeMap>>` cache, `settings.rs` persists `ai-settings.json` under the app data directory, `providers.rs` enumerates supported providers (currently only `deepseek`), and `types.rs` defines all serde-serializable request/response structs. The `mod.rs` re-exports public types and non-command helpers, and declares `#[tauri::command]` functions that thin-wrap the `_impl` implementations in other files, keeping macro-generated symbols resolvable at the path referenced by `main.rs`. Dependency direction flows outward from commands → feature modules → shared primitives (providers, keyring, settings); cross-cutting concerns like third-party sharing checks are centralized in `chat::ensure_third_party_ai_sharing_allowed` and reused by both chat and auto-mark paths.
