The module is organized as a flat collection of one tool per file under `src-tauri/src/tools/`, each implementing the `rig::tool::Tool` trait with a `NAME` constant, typed `Args` struct (serde-serialized), and an async `call` method. `mod.rs` re-exports every tool type and provides a global, thread-safe dispatch mechanism via `OnceLock<RwLock<Option<ToolCallHandler>>>` — tools do not perform work directly but instead call `dispatch_tool_call(name, args)` which forwards to a handler registered at runtime by the Tauri application layer. Shared mutable state (e.g. `ProxyBufferState` in `buffer.rs`) is passed into tools that need it (see `SendHexTool`). Error handling uses crate-local `thiserror` types (`AppToolError`, `ToolError`) rather than panics. Dependency direction is strictly inward: tool files depend only on `super::dispatch_tool_call` and shared types; nothing in this module depends back on the Tauri frontend.
