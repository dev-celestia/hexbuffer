The proxy requires a CA certificate under `<app_data_dir>/.hexbuffer/ca.pem` and `ca-key.pem`; `ensure_ca_exists()` auto-regenerates them if missing. Port binding falls back up to 20 ports above the preferred port when `reuse=false`, or actively kills other processes listening on the port when `reuse=true` via `lsof`/`kill`. The proxy is started through `proxy::run(ProxyConfig, AppHandle)` which blocks on a tokio runtime until shutdown.
