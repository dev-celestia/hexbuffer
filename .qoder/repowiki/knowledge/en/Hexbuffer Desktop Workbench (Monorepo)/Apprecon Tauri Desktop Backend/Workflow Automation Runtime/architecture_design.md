The module is a self-contained Tauri runtime built around a single shared `AutomationRuntimeState` (a `Mutex<AutomationRuntimeInner>`) exposed via `tauri::State`. `mod.rs` declares all public Tauri commands (`automation_sync_workflows`, `automation_run_workflow`, `automation_abort/pause/resume_workflow`, etc.) and re-exports the ingestion entry points for external subsystems. Execution flows through `execution::run_workflow_task`, which walks nodes in BFS order using edges to propagate data; node behavior is dispatched by `actions::execute_runtime_action` based on an `actionType` string, while `condition::evaluate_condition` handles branching. Trigger sources are isolated per file (`live_traffic`, `scheduled`, `port_scan`, `intercept`, `websocket`, `page_crawled`, `scan_completed`) and each exposes an `ingest_*` function that enqueues jobs into per-trigger `VecDeque`s managed by `state.rs`. UI feedback is funneled through a backpressured telemetry pipeline in `events.rs` that batches items with throttling and emits them over the `automation:ui-batch` Tauri event. Concurrency is controlled by `live_traffic_concurrency` and run tokens prevent stale completions after aborts or superseding manual runs.
