The repository is a monorepo orchestrated by pnpm workspaces. The root `package.json` defines shared scripts (`dev`, `tauri`, `docs`, `deploy`) that bootstrap the three runtime layers: the React/Vite frontend under `src/`, the Rust/Tauri backend under `src-tauri/`, and the Next.js/Fumadocs docs site under `docs/website`. The frontend communicates with the backend exclusively through Tauri v2 IPC commands exposed by `src-tauri/src/main.rs`, which wires together the MITM proxy, crawler, AI agent, port scanner, SQLi scanner, automation engine, and SQLite persistence. The docs site is independent but versioned alongside the app. Build and packaging are delegated to Bash scripts under `scripts/` invoked via `pnpm deploy`, while GitHub Actions in `.github/workflows/` coordinate multi-platform Tauri builds and docs deployment. Agent skill definitions under `.agents`, `.gemini`, and `.opencode` provide cross-toolchain design guidance consumed by both developers and AI assistants.
