Linux build requires running `sudo bash scripts/setup-linux-deps.sh` first (installs WebKitGTK 4.1, Rust toolchain, Node 20+, pnpm). Cross-compiling Windows from non-Windows requires `cargo install --locked cargo-xwin`. R2 upload needs `R2_ENDPOINT`, `R2_BUCKET`, and optionally `UPDATER_BASE_URL` set in `.env`. The default deploy flow is `pnpm run deploy` (auto-increment patch version, build, upload); explicit versions use `./scripts/build.sh 2026.1.1` or `pnpm run deploy -- --version 2026.1.1`.
