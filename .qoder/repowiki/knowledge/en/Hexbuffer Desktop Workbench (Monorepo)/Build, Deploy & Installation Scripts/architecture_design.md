Flat collection of standalone bash scripts under `scripts/`, each self-contained with its own CLI (`--help`, argument parsing via `case`), error handling (`set -euo pipefail`), and root/directory resolution (`ROOT=$(cd "$(dirname "$0")/.." && pwd)`). `build.sh` is the central orchestrator: it parses flags (`--upload`, `--windows`, `--windows-all`, `--all`, `--bump`, `--version`), optionally calls `bump-version.sh`, invokes `pnpm run tauri build` (with `cargo-xwin` for cross-compilation), then uploads bundles/signatures/installers to Cloudflare R2 via an `aws s3 --endpoint-url` wrapper, updating a shared `latest.json` manifest. `deploy.sh` is a thin pnpm wrapper that forwards arguments to `build.sh`. `install.sh` is a public-facing installer that downloads from `OXBUFFER_RELEASES_URL/latest.json`, verifies SHA-256 checksums, and installs DMG on macOS or AppImage on Linux. Supporting scripts handle environment setup (`setup-linux-deps.sh` detects apt/dnf/pacman and installs WebKitGTK 4.1 + Rust + Node 20+), dependency updates (`update-deps.sh` runs `cargo update`), and macOS-specific helpers (`clear_routes.sh`, `fix-packet-capture-permissions.sh`). Dependency direction is one-way: higher-level scripts call lower-level ones; nothing imports back into this module.
