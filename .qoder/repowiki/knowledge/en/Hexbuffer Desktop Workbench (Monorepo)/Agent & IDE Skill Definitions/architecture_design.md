Each top-level directory (.agents/skills, .gemini/skills, .opencode/skills) is a skill registry consumed by its respective agent/IDE. Every skill is a self-contained folder with a front-matter SKILL.md that declares name, description, and optional flags (e.g., disable-model-invocation). The dominant skill is `impeccable`, which bundles not only its SKILL.md but also a full Node.js toolkit under scripts/ (context gathering, live browser iteration, detector, hooks, palette generation) and agent configuration files under agents/ (openai.yaml + two TOML-defined sub-agents: asset_producer and manual_edit_applier). The other skills are pure knowledge documents: apple-design (WWDC fluid-interface principles), review-animations (Emil Kowalski animation review standards with STANDARDS.md), categorized-tailwind-css (class grouping convention), and emil-design-eng (design engineering philosophy). .opencode/plans holds markdown project plans unrelated to skill execution. Dependency direction is one-way: SKILL.md files instruct the agent how to invoke scripts; scripts never reference the agent framework — they are plain Node .mjs modules.
