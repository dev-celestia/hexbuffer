The impeccable skill requires running `node .agents/skills/impeccable/scripts/context.mjs` once per session before any command, optionally with `--target <path>` for monorepo routing. Sub-commands (`craft`, `shape`, `audit`, `polish`, `live`, etc.) each have a corresponding `reference/<command>.md` that must be loaded after setup. Pinning/unpinning shortcuts is done via `node .../scripts/pin.mjs <pin|unpin> <command>`. Hooks management uses `$impeccable hooks <on|off|status|...>` and delegates to `reference/hooks.md`.
