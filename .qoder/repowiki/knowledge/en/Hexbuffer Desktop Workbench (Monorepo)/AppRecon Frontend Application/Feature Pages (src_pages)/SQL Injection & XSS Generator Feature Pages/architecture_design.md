Each page follows a consistent three-layer layout: index.tsx is a presentational shell that composes UI components and passes props down; hooks/use-*-page.ts owns all state, derived values, and side effects (Tauri IPC for the SQLi scanner, local memoization for the XSS generator); components/ holds small focused panels (scan toolbar, parameters panel, vulnerabilities/extraction tabs for SQLi; payload library and builder panels for XSS). Shared constants live in constants.ts (technique labels, severity colors, payload catalog) and domain types in types.ts. The SQLi page communicates with the Rust backend via @tauri-apps/api/core invoke and listen using a unique crypto.randomUUID() scan id to scope sqli-progress events. Export helpers are isolated in lib/export-helpers.ts (JSON/CSV) and lib/encoding-functions.ts (XSS encoders). Dependency direction is strictly one-way: index -> hook + components, hooks -> lib/constants/types, components only receive props.
