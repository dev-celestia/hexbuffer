The module follows a clear separation of concerns: `index.tsx` is the single page entry that composes UI components and wires up `@dnd-kit`'s `DndContext`, `MouseSensor`, `TouchSensor`, and `DragOverlay`. All mutable state (cards, groupBy mode, dragging id, modal visibility) lives in the `use-kanban-page.ts` custom hook, which also derives columns via `useMemo` based on the current `groupBy` mode. Components are presentational and receive data/callback props — `KanbanColumnPanel` uses `useDroppable`, `KanbanCardItem` uses `useDraggable`, while `KanbanToolbar`, `KanbanAddModal`, and `KanbanDetailModal` handle user actions that bubble back into the hook's setters. Types (`types.ts`) define the shared `KanbanCard`, `KanbanColumn`, `SubTask`, `Priority`, and `GroupBy` contracts; `constants.ts` holds immutable configuration (priority labels/colors, default columns for each grouping, seed cards, and group options). Dependency direction is strictly one-way: components → hook → constants/types, with no cross-component imports.
