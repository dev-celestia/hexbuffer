The module is a self-contained React page (`index.tsx`) composed of a `TabbedPageLayout` wrapper plus a left sidebar (tree or dashboard) and a right main area. State is centralized in an external Zustand store (`@/stores/regression`, accessed via `useRegressionStore`) and surfaced through the `useRegressionPage` hook, which owns tab lifecycle, active test case selection, run orchestration, single-step execution, and derived counters. The page renders into three layers: (1) layout shell (`RegressionHeader`, `RegressionEmptyState`, `RegressionTree`, `RelationalDashboard`), (2) editor layer (`TestSuiteEditor` + `StepFlowBuilder` + `StepFlowCanvas` built on `@xyflow/react` with a custom `StepNode` node type), and (3) execution layer (`TestRunner` + `TestResults` + `PlaywrightLogPanel`). Types are declared in `types.ts` and mirrored by sidecar Zod schemas; constants for step kinds, labels, icons, and AI prompts live in `constants.ts`. The canvas definitions (`lib/canvas-definitions.ts`) register the single node type and shared edge styling, keeping the flow library decoupled from business logic.
