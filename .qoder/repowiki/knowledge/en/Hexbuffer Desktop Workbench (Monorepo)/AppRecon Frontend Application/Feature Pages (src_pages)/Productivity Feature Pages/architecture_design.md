Each subdirectory under `src/pages/` is an independent React page component (`AutomationPage`, `RegressionPage`, `DocumentsPage`, `KanbanPage`) exported from its own `index.tsx`. Every page follows the same layout contract: it wraps its content in the shared `TabbedPageLayout` component (with `tabs`, `activeTabId`, `onTabChange`, `onTabAdd`, `onTabRename`, `onTabClose` props) and owns a single page-scoped hook (`use-automation-page`, `use-regression-page`, `use-documents-page`, `use-kanban-page`) that manages tab state, local UI state, and cross-component data. Canvas-based pages (workflow, regression) additionally wrap their content in `ReactFlowProvider` from `@xyflow/react`; the kanban page uses `DndContext` from `@dnd-kit/core`; the markdown page has no global provider. Each page composes its own `components/`, `hooks/`, `lib/`, and `nodes/` directories with no cross-page imports, keeping features isolated while sharing the common tabbed-shell and hexbuffer-ui primitives.
