React + TypeScript with Tailwind CSS styling via `cn()` utility; AWS S3 SDK (`@aws-sdk/client-s3`, `@aws-sdk/s3-request-presigner`) for R2 operations; Tauri plugins (`@tauri-apps/plugin-fs`, `plugin-dialog`, `plugin-opener`, `api/path`, `api/core`) for native file system access and IPC; `sonner` for toast notifications; `hexbuffer-ui` for primitive components (Button, Input, AlertDialog); Phosphor Icons for iconography.
