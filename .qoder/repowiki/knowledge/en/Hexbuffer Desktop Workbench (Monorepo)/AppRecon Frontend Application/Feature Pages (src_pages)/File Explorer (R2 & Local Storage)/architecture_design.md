Single-page React component (`index.tsx`) acts as the root layout and tab switcher between two data sources: R2 (Cloudflare) and Local filesystem. State is split across two custom hooks — `use-file-explorer.ts` manages R2 bucket discovery, S3 commands via `@aws-sdk/client-s3`, object listing, upload (direct or multipart), caching to the app's local data dir, and presigned/public URL generation; `use-local-storage.ts` manages a dedicated workspace directory under the OS document folder with CRUD operations through `@tauri-apps/plugin-fs`. Both hooks expose a parallel API surface so `index.tsx` renders the same `FileToolbar` + `FileGrid` UI for either source. The S3 client uses a custom `tauriRequestHandler` (`lib/tauri-s3-transport.ts`) that bridges AWS SDK HTTP requests to Tauri Rust commands via `invoke('r2_http_request')`, enabling network calls from the renderer process. Multipart uploads are delegated to `lib/s3-multipart-upload.ts` which batches part uploads concurrently (batch size 3). UI components live under `components/`: shared `file-grid.tsx`, `file-toolbar.tsx`, `explorer-sidebar.tsx`, `explorer-details-pane.tsx`, plus source-specific renderers `cloud/explorer-grid.tsx` and `local/local-grid.tsx`. File icons are resolved by `lib/file-icons.ts` via exact-name, extension, and folder-name lookup tables against SVG assets under `/src/assets/explorer-icon/`. Types are centralized in `types.ts` (`R2Item`, `R2Credentials`) and constants (presigned URL expirations, previewable extensions, multipart thresholds) in `constants.ts`.
