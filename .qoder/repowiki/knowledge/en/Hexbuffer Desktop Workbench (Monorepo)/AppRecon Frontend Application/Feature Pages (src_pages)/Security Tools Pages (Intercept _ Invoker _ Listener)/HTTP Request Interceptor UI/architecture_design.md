The module is a React page (`index.tsx`) built on `TabbedPageLayout` from the shared UI layer. State is centralized in a Zustand store (`state/intercept-store.ts`) created with `persist` middleware for tab/capture-host persistence. The store owns all business logic: tab management, capture-host filtering (with wildcard `*.` support), request/response forwarding via Tauri triggers (`@/triggers/intercept`), and scope synchronization through `api.ts` which calls backend commands via `@tauri-apps/api/core`. The page composes two side-by-side resizable panels — `InterceptQueuePanel` (left) and `InterceptRequestPanel` (right) — each driven by its own hook (`use-queue-panel`, `use-request-panel`) plus a shared `use-bypass-panel` hook. A top-level `use-intercept-page` hook handles periodic polling (`setInterval` every 1s) to refresh status and paused requests. Utility helpers in `lib.ts` convert between raw HTTP messages and the binary `PausedRequest` shape defined in `types.ts`. Dependency direction is strictly one-way: components → hooks → store → api/triggers; no cross-component imports bypass the store.
