Predefined payloads are auto-discovered at build time via `import.meta.glob('../payload/**/*', { eager: true, query: '?raw' })` in `data/predefined-payloads.ts`; adding new wordlist files under `src/pages/invoker/payload/` automatically registers them without code changes. Runtime payload files are loaded through Tauri's `open()` dialog filtered to `*.txt`, `*.lst`, `*.wordlist` extensions.
