The module is a React page (`index.tsx`) composed around `TabbedPageLayout` from the shared UI layer. It follows a clear separation of concerns:
- **Types & defaults** (`types.ts`, `constants.ts`) define the canonical `AttackConfig`, `PayloadConfig`, `HttpRequest`, `AttackResult`, etc., and provide factory helpers like `createDefaultAttackConfig` and position-parsing utilities (`findPayloadPositions`, `applyPayloadToPosition`).
- **State management** lives in an external Zustand store (`@/stores/invoker`); the page's own hook `use-page.ts` slices store state via `useShallow` and derives computed values (active tab, progress, start-blocking reasons) before exposing a flat props surface to components.
- **UI components** under `components/` are presentational: `InvokerConfigDialog` (tabbed Request/Attack/Payloads editor), `InvokerResultsPanel`, `InvokerResultInspector`, `InvokerPayloadDialog`, `InvokerPayloadPresetDialog`, plus small helpers (`progress.tsx`, `preview-panel.tsx`). The config editor is split into sub-tabs under `components/invoker-config/config/` (`attack-tab.tsx`, `payloads-tab.tsx`, `request-tab.tsx`, `number-input-field.tsx`).
- **Hooks** (`hooks/use-page.ts`, `hooks/use-payloads.ts`, `hooks/use-filters.ts`) encapsulate side effects — file loading via Tauri `@tauri-apps/plugin-dialog` and `@tauri-apps/plugin-fs`, toast notifications, and result filtering.
- **Data layer** (`data/predefined-payloads.ts`) uses Vite's `import.meta.glob` with `{ eager: true, query: '?raw' }` to bundle all `.txt` files under `payload/` as predefined wordlists, grouped by directory into categories.
- **Static payloads** live under `payload/` (BurpSuite-ParamMiner, DNS, api, usernames, Logins.fuzz.txt) and are consumed only through the predefined payloads loader.
- Dependency direction is one-way: components → hooks → Zustand store; types flow outward to consumers via `types.ts`; no component imports another sibling component directly except through the `config/index` barrel.
