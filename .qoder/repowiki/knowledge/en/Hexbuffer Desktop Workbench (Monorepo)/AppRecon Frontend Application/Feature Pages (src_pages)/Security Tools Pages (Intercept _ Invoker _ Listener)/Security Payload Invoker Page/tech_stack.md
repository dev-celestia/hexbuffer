React + TypeScript with Zustand for global state (`@/stores/invoker`), `hexbuffer-ui` for primitives (Alert, Button, Tabs, Badge), `@phosphor-icons/react` for icons, `sonner` for toast notifications, and Tauri plugins (`@tauri-apps/plugin-dialog`, `@tauri-apps/plugin-fs`) for native file access. Vite's `import.meta.glob` with raw queries bundles static payload wordlists at build time.
