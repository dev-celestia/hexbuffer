The module is a single-page feature rooted at `index.tsx`, which renders a `TabbedPageLayout` with two tabs: Hosts and Interactions. State lives in an external Zustand store (`@/stores/listener`) accessed through the `useListenerPage` hook, which orchestrates data loading, auto-polling every 10 seconds, filter-driven re-fetching, and auto-generation of default callback payloads per server. The `api.ts` layer bridges Tauri commands (`invoke('list_collaborator_*', ...)`) to the frontend by mapping snake_case Rust structs to camelCase TS interfaces defined in `types.ts`. UI components under `components/` are presentational and receive all state/actions as props; their local logic is extracted into hooks under `components/hooks/` (`use-hosts-panel`, `use-interactions-panel`, `use-interaction-detail`). A small `constants.ts` defines sub-tab metadata, and `metrics.tsx` is a pure stats display component. Dependency direction is strictly one-way: index → hooks → api → Tauri, with no cross-component imports beyond shared types.
