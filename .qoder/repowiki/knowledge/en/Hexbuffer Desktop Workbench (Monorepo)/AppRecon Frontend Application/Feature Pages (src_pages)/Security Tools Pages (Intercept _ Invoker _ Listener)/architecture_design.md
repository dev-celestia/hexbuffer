Each child is an independent `src/pages/<feature>/index.tsx` page that owns its own routing entry, local API client (`api.ts`), typed models (`types.ts`), page-level hook (`use-*-page.ts`), and a `components/` tree split into presentational components and co-located `hooks/`. The three pages are peers under `src/pages/` and are wired into the app's top-level router; they do not import each other but share the same structural contract: a page index exports a component, a page hook encapsulates navigation/tab state, and a store/hook pair manages feature-specific state. Cross-page communication is absent — each page talks to the backend via its own `api.ts` fetch calls and exposes no shared module.
