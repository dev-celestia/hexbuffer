React with TypeScript; styling via Tailwind CSS classes passed through a `cn()` utility from `@/lib/utils`; UI primitives from `hexbuffer-ui` (Button, ButtonGroup); icons from `@phosphor-icons/react`; notifications via `sonner` toast; hashing uses `crypto-js` for MD5/SHA/Ripemd algorithms, while JWT signing uses the Web Crypto API (`crypto.subtle` HMAC) and Base64url is implemented manually; the encoder page also uses `crypto-js` for Base64/Hex conversions.
