Each of the three pages (`jwt`, `hash`, `encoder`) follows an identical internal layout: an `index.tsx` page component that composes a toolbar and input/output panels, a `hooks/use-*-page.ts` custom hook owning all state and side effects, a `lib/*-functions.ts` module with pure transformation logic, a `types.ts` for shared interfaces, a `constants.ts` for UI options, and a `components/` folder with small presentational pieces. The JWT page additionally persists its mode and form fields through a Zustand store (`@/stores/jwt-store`) while ephemeral derived state (decoded payload, vulnerabilities, errors) lives in local `useState`. Dependency direction is strictly one-way: `index.tsx` → `hooks/*` → `lib/*`; components receive data via props and never import business logic directly. Each page exports a single named component (`JwtPage`, `HashPage`, `EncoderPage`) as its entry point.
