The module is a React page built on `TabbedPageLayout` with workspace tabs managed by `useRepeaterPage`, which reads/writes the global `@/stores/repeater` and `@/stores/collections` stores via Tauri `invoke` calls. The page composes two main panels: `WorkspacePanel` (left-right split) containing a `CollectionsTree` (a dnd-kit powered hierarchical list of stashes/endpoints with inline create, rename, delete, import/export) and a `ForgePanel` (request/response editor with sub-panels under `forge-panel/`). Cross-cutting concerns are isolated in `lib/`: `collection-io.ts` handles JSON export/import using Tauri filesystem/dialog plugins, and `script-sandbox.ts` executes user scripts via `new Function` with a restricted `pm`/`script`/`expect` API. Network calls go through `api.ts` (`send_repeater_request`) and Tauri commands like `save_stash`. State flows from Zustand stores into components; UI-only state lives in hooks/components. Dependency direction is one-way: components → hooks/lib → stores/Tauri invoke.
