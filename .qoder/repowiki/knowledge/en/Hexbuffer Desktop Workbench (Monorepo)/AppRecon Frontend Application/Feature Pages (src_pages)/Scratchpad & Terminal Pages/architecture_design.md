Each page follows the same layout: an `index.tsx` entry renders a page component that composes a `use*-page` hook (state + side effects) with child components in `components/`. The scratchpad page (`src/pages/scratchpad/`) pairs a `ScratchpadSidebar` with a `ScratchpadEditorPane` inside a flex container; the terminal page (`src/pages/terminal/`) uses a shared `TabbedPageLayout` from `@/components/tabs-layout/tabbed-page-layout` to host multiple `TerminalContainer` instances plus a `TerminalToolbar` and optional `TerminalSidebar`. State is split between local React state in the hooks and global stores: scratchpad uses `@/stores/scratchpad` via Zustand, while terminal reads `@/stores/terminal` and dispatches mutations through `@/triggers` (action creators). The terminal hook also directly manipulates xterm instances cached in a module-level `terminalInstances` Map, using a callback ref (`registerContainer`) to bind each instance to its DOM element. Both pages persist UI preferences (sidebar open state) in `localStorage`.
