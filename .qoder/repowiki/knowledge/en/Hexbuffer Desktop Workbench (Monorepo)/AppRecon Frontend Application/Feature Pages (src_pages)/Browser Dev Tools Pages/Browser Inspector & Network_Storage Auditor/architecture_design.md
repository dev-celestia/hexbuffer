The module is organized as a React page (`index.tsx`) built on `TabbedPageLayout` from the shared UI layer, with three tabs: Network, Storage, and Console. State and CDP communication are centralized in the `useInspectExternal` hook, which owns a WebSocket connection to the target browser's `webSocketDebuggerUrl`, manages a pending-command Map for request/response correlation, and exposes actions like `connect`, `disconnect`, `fetchTargets`, `openBrowser`, `getResponseBody`, `emulateNetwork`, and storage CRUD. The `components/` directory holds presentational components (`network-monitor.tsx`, `storage-auditor.tsx`, `json-viewer.tsx`, `event-row.tsx`, `target-selector.tsx`) that receive data and callbacks via props from the hook. Cross-cutting concerns are split into `hooks/use-debugger-page.ts` (Tauri event subscription for workflow events), `api.ts` (Tauri `invoke` calls for `open_cdp_browser` and `get_cdp_targets`), `types.ts` (shared interfaces for `Target`, `NetworkRequest`, `Cookie`, `ConsoleLog`, etc.), `constants.ts` (port defaults, tab definitions, color maps), and `lib/format-timestamp.ts`. Dependency direction flows downward: `index.tsx` → `useInspectExternal` hook → Tauri `invoke` + WebSocket; components only consume hook state and never call Tauri directly.
