Both `browser/index.tsx` and `inspector/index.tsx` are top-level page components mounted by the app router, each wrapped in the shared `TabbedPageLayout` from `@/components/tabs-layout`. The browser page drives a crawl session via Tauri triggers (`startBrowserCrawl`, `stopBrowserCrawl`, `toggleBrowserCrawl`) imported from `@/triggers` and exposes a resizable multi-panel workspace (tree, detail, AI insights, action log) orchestrated by per-panel hooks under `components/hooks/`. The inspector page connects to a remote Chrome instance through the `useInspectExternal` hook (CDP over WebSocket) and renders Network, Storage, and Console tabs. The two pages are independent front-end surfaces; they do not import each other but share the same UI primitives (`hexbuffer-ui`), icon set (`@phosphor-icons/react`), and the tabbed-page container, making them parallel entry points into different debugging workflows rather than a single cohesive tool.
