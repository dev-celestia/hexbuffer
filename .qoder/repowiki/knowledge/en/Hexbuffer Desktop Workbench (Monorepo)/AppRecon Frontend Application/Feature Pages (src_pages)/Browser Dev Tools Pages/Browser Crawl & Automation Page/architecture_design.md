The module is organized as a single-page feature rooted at `index.tsx`, which composes a `TabbedPageLayout` containing four resizable sub-panels: `CrawlTreePanel`, `PageDetailPanel`, `AiInsightsPanel`, and `ActionLogPanel`. State lives in the external `useBrowserAutomationStore` (Zustand) and is consumed via the `useBrowserAutomationPage` hook (`hooks/use-page.ts`), which wires Tauri event listeners (`ai-browser:*`) to store actions. Each panel has a co-located React hook under `components/hooks/` (e.g. `use-crawl-tree-panel`, `use-ai-insights-panel`) that encapsulates its own filtering, selection, and UI state. Pure data utilities live in `lib/crawl-data.ts` (tree building, overview derivation, formatting). Types are centralized in `types.ts` and constants (default config, labels, severity lists) in `constants.ts`. The dependency direction is one-way: components → hooks → store/Tauri events; pure functions in `lib/` have no side effects.
