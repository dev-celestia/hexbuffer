No build or setup script is specific to this module; it runs as part of the Tauri desktop app. It depends on the Rust backend exposing `mock_forge_get_domains`, `mock_forge_get_routes`, `mock_forge_get_logs`, `mock_forge_toggle_domain`, `mock_forge_add_domain`, `mock_forge_delete_domain`, `mock_forge_add_route`, `mock_forge_update_route`, and `mock_forge_delete_route` commands, and emitting a `mock-forge-log` event.
