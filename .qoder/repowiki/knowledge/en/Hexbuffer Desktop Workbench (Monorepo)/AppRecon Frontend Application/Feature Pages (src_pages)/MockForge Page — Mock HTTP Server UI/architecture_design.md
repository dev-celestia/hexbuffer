The module is a self-contained feature page built around a tabbed layout (`TabbedPageLayout`) with three sub-tabs: Domains, Routes, and Logs. `index.tsx` wires the top-level `MockForgePage` component to the shared `TabbedPageLayout` and delegates rendering of each tab's content to `MockForgeContent`, which renders `<DomainsPanel>`, `<RoutesPanel>`, and `<LogsPanel>` as `TabsContent` entries. State is centralized in a Zustand store (`@/stores/mock-forge`) accessed through the `useMockForgePage` hook, which also handles Tauri IPC via `invoke('mock_forge_*')` for CRUD on domains/routes and subscribes to the `mock-forge-log` event stream to prepend incoming logs (capped at 200). Each panel has its own focused React hook under `components/hooks/` (`use-domains-panel`, `use-routes-panel`, `use-logs-panel`) that encapsulates local search/filter state and derived views. Cross-feature integration happens through direct calls into other stores (`useRepeaterStore`, `useCollectionsStore`, `useNavStore`) when sending requests to the Repeater. Types are declared once in `types.ts` and constants (sub-tab definitions, HTTP methods, default body) live in `constants.ts`.
