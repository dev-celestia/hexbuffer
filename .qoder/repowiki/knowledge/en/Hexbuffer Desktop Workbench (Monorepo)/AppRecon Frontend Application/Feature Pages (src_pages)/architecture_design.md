Each subdirectory under src/pages/ is an independent React feature page with a uniform layout: an index.tsx entry point, a use-*-page.ts hook for page-level state, a components/ folder of UI pieces, optional hooks/, lib/, types.ts, and constants.ts. Pages are registered and rendered by the app's tabbed navigation shell rather than routing, so they share the same TabbedPageLayout container and Tauri backend integration pattern. Cross-page communication is minimal; most features communicate only through the Tauri IPC layer to their respective backends, keeping each feature isolated while reusing the common page scaffolding.
