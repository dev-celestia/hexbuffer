The app is bootstrapped in `main.tsx` with React StrictMode, BrowserRouter, ThemeProvider, and the AppLayout shell; `AppRoutes` (in `App.tsx`) lazily imports each feature page under `/src/pages/*` as a route. The layout system (`@/layout`) wraps all routes and provides the taskbar dock, floating window workspace, assistant pane, and footer. Cross-cutting state lives in `@/stores` (Zustand) and is consumed by both layout and feature pages. Global side effects are registered at the root via trigger modules under `@/triggers/*` (live-traffic, browser, intercept, etc.) which start/stop watchers through Tauri IPC. Feature pages follow a consistent internal structure of `index.tsx`, `components/`, `hooks/`, `lib/`, `types.ts`, and `constants.ts`, keeping each tool self-contained while sharing primitives from `@/components/ui`, `@/components/ai-elements`, and `@/components/tabs-layout`. Tauri integration is centralized through `@/lib/tauri-types.ts`, `useTauriFocusFix`, and direct `invoke()` calls for window management.
